# Business Context

Thư mục chứa các tài liệu liên quan đến nghiệp vụ phần mềm.

## Cấu trúc gợi ý

```text
business/
├── processes/        # Quy trình nghiệp vụ, luồng xử lý
├── diagrams/         # Sequence diagram, flowchart, BPMN
├── templates/        # File template nghiệp vụ (invoice, report...)
└── glossary.md       # Thuật ngữ nghiệp vụ
```

## Hướng dẫn

- Đặt file theo từng subfolder tương ứng
- Dùng PlantUML hoặc Mermaid cho diagram
- Cập nhật khi có thay đổi nghiệp vụ lớn
