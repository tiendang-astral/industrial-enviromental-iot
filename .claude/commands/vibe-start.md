# /vibe-start

Đọc toàn bộ context và nắm codebase hiện tại.

## Steps

1. Đọc tất cả file trong `context/`
2. Nếu có `.codegraph/`, dùng `codegraph_explore` để nắm cấu trúc codebase
3. Chỉ lên tiếng nếu có gì cần flag — thiếu context hoặc mâu thuẫn giữa các file — nêu ngắn gọn rồi dừng, chờ yêu cầu tiếp theo
